## 项目简介

Stock Analyst 是一个为中长期投资者设计的Web版投资分析工具。通过技术面、基本面、情绪面三个维度的综合评分，为A股ETF提供理性的"买/卖/持有"决策建议。

### 核心特点

- **多维度分析**：技术面(40%) + 基本面(40%) + 情绪面(20%)
- **实时数据**：基于东方财富/AkShare的权威数据源
- **移动友好**：响应式设计，手机/电脑均可访问
- **自动更新**：每15分钟自动刷新数据
- **数据透明**：清晰标注数据时间戳

## 快速开始

### 环境要求

- Python 3.10 或更高版本
- pip 包管理器

### 安装步骤

1. **克隆仓库**
```bash
git clone https://github.com/kennyzhang2026/stock_analyst.git
cd stock_analyst
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **启动服务**
```bash
# Windows
start.bat

# Linux/Mac
python backend/app.py
```

4. **访问系统**
- 电脑端：http://localhost:5000
- 局域网：http://192.168.x.x:5000（需替换为实际IP）

## 使用说明

### 基本操作

1. **输入代码**：在搜索框中输入ETF代码（如 513120）
2. **查看分析**：点击"分析"按钮获取综合评分
3. **刷新数据**：点击"刷新"按钮手动更新最新数据

### 支持的标的

当前版本支持ETF基金分析，包括但不限于：

| 代码 | 名称 |
|------|------|
| 513120 | 港股创新药ETF |
| 510300 | 沪深300ETF |
| 510500 | 中证500ETF |
| 159915 | 创业板ETF |

更多ETF代码正在持续添加中。

### 评分说明

| 总分范围 | 操作建议 | 颜色标识 |
|----------|----------|----------|
| ≥ 70 分 | **买入 / 增持** | 绿色 |
| 50-69 分 | **持有** | 黄色 |
| 30-49 分 | **观望 / 轻仓** | 橙色 |
| < 30 分 | **卖出 / 减持** | 红色 |

### 数据时间

系统会明确显示数据的时间戳：
- 交易时间内：显示实时数据时间
- 非交易时间：标注"非交易时间显示最后收盘价"

## 已知限制

### 数据相关

- **实时报价API不稳定**：东方财富push API在某些网络环境下被阻断，系统会自动切换到K线数据获取最新收盘价
- **非交易时间数据**：盘后/周末显示最后交易日收盘价
- **单一标的支持**：当前仅支持ETF基金，不支持个股

### 算法相关

- **简化版估值**：ETF估值使用回撤幅度简化计算，个股估值评分暂时固定
- **板块景气度**：MVP阶段使用固定规则，未接入新闻情感分析

### 功能相关

- **无数据持久化**：刷新页面后历史分析清空
- **无价格提醒**：不会主动推送价格变动
- **单用户设计**：无账户系统，多人使用会共享缓存

## 常见问题

### Q: 为什么显示"非交易时间显示最后收盘价"？

A: 股市交易时间为周一至周五 9:30-15:00。非交易时间内，系统显示最后交易日的收盘数据。

### Q: 数据更新频率是多少？

A: 系统每15分钟自动更新一次，您也可以点击"刷新"按钮手动更新。

### Q: 支持哪些数据源？

A: 当前使用东方财富API和AkShare，两者互为备份，确保数据可用性。

### Q: 为什么有时候数据获取失败？

A: 可能是网络连接问题。系统已实现多数据源自动切换，如仍有问题请检查网络设置。
