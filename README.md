# A股/基金投资分析决策系统

## 项目目标

为持有的中国A股及基金制定理性的"买/卖/持有"决策。

## 核心功能

1. **持仓管理**: 录入个人持有的股票代码和基金代码
2. **数据获取**: 实时/准实时获取行情、基本面信息
3. **多维分析**: 价格、技术指标、基本面、市场情绪综合分析
4. **决策建议**: 生成符合用户风险偏好的操作建议

## 分析模型设计

### 多因子评分体系

```python
综合评分 = W1×技术面评分 + W2×基本面评分 + W3×情绪面评分

技术面评分 = 趋势强度 + 动量指标 + 位置估值
基本面评分 = 盈利能力 + 成长性 + 估值水平
情绪面评分 = 资金流向 + 市场热度
```

### 决策规则示例

| 评分区间 | 操作建议 | 条件说明 |
|----------|----------|----------|
| > 80分 | 买入 | 多维度共振向上 |
| 60-80分 | 持有/增持 | 基本面稳健 |
| 40-60分 | 观望/持有 | 等待明确信号 |
| < 40分 | 卖出/减持 | 风险大于机会 |

## 首期分析示例: 港股创新药ETF 513120

### 基本信息
- 代码: 513120 (上海证券交易所)
- 类型: ETF - 跟踪港股创新药板块
- 主要持仓: 药明生物、药明合联、康方生物、亚盛医药等

### 分析维度
1. **技术面**: 趋势方向、支撑阻力、量价配合
2. **基本面**: 板块估值、政策环境、持仓公司业绩
3. **资金面**: 融融余额、北向资金流向
4. **情绪面**: 市场对医药板块的关注度

## 行业最佳实践

### 1. 多策略验证
- 技术分析 + 基本面分析相互验证
- 避免单一指标决策

### 2. 风险控制优先
- 设置止损/止盈点位
- 分散持仓，集中度控制

### 3. 定期复盘
- 每周/每月回顾决策效果
- 根据实盘反馈调整模型参数
